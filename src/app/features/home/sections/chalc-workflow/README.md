# Recorrido Chalc

Sección del inicio que explica cómo Christian trabaja con Chalc. Presenta siete etapas y sus artefactos; no llama APIs ni ejecuta comandos. Posee únicamente la selección, reproducción opt-in, temporizador y preferencia de movimiento. Depende de core/i18n y del catálogo local de pasos, sin imports a otros features. Los tests montan Home para verificar el contrato de integración y controles visibles.

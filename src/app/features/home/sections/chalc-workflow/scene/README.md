# Escena ilustrativa de Chalc

Escena SVG/CSS propia del recorrido del inicio. Recibe etapa, reproducción y preferencia de movimiento del padre; emite selección de rol/etapa. No posee timer, no ejecuta comandos ni llama APIs. Personajes representan líder, desarrollador y revisor; gate/asesor/memoria son herramientas y la aceptación es humana. Las animaciones mueven avatares y documentos; la narración permanece quieta. Pausa conserva fotograma y selección manual/reduced-motion conserva composición estática legible.
